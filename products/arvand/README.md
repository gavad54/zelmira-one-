# ARVAND — مستقل در خانواده VAYRO

## جایگاه محصول
ARVAND یک اپلیکیشن مستقل مستقیم زیر VAYRO است؛ زیرمجموعه ARIA نیست. دامنه اصلی آن تجارت بین‌الملل و بازرگانی است. حوزه‌های پشتیبان شامل تأمین‌کننده و شریک تجاری، مناقصه، انطباق، لجستیک، گمرک و اطلاعات سفر/مقصد هستند.

## تجربه کاربری هدف
- داشبورد بازرگانی و پرونده‌های فعال
- جست‌وجو و ارزیابی تأمین‌کننده و شریک
- درخواست پیشنهاد قیمت (RFQ) و مناقصه
- مقایسه پیشنهادها و شرایط خرید
- مدیریت پرونده صادرات/واردات و اسناد
- رهگیری حمل، استثناهای لجستیک و وضعیت گمرکی
- ارزیابی ریسک، کیفیت و انطباق
- ابزارهای پشتیبان سفر و مقصد برای پرونده‌های بین‌المللی

## ماژول‌های انتقالی
فهرست 14 شناسه overlay در `module-catalog.json` ثبت شده است. شناسه‌ها ثابت می‌مانند و به‌عنوان شناسه تاریخی مبدا نیز قابل ردیابی‌اند. این انتقال شامل 5 قابلیت تاریخی و 9 ایده طراحی‌شده است.

## مرز محصول
- ARVAND مالک داده و گردش‌کار تجارت بین‌الملل است.
- ARIA فقط از طریق اتصال مجاز می‌تواند کاربر را به ARVAND هدایت کند؛ مالک اجرای معامله نیست.
- ARMIN MARKET مالک بازار و فروشگاه عمومی است؛ داده بازار مجاز می‌تواند از API قراردادشده مصرف شود.
- LEADORA مالک عملیات مشتری و بازاریابی/رشد است؛ فقط از داده مجاز استفاده می‌کند.
- حسابداری، دفترکل و ERP در ARIANA باقی می‌ماند.
- ARVAND طرف معامله، نگهدارنده وجه یا تضمین‌کننده کالا/حمل نیست مگر در قرارداد و مجوز حقوقی جداگانه؛ مسئولیت طرفین معامله باید شفاف باشد.

## معماری پیشنهادی
- Android/Web client مستقل با فارسی RTL و انگلیسی
- Backend مستقل با API versioned
- پایگاه داده مستقل و tenant isolation
- سرویس فایل و اسناد با دسترسی حداقلی، نسخه‌بندی و audit log
- اتصال‌های تأمین، حمل، گمرک و پرداخت فقط از طریق provider رسمی و مجاز
- قرارداد SSO از VAYRO با audience و scope مخصوص ARVAND
- عملیات حساس با preview و تأیید انسانی
